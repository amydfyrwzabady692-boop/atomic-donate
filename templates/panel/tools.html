هر ابزار یک Browser Source جدا در OBS است. لینک را کپی کن، در OBS از Sources → Browser اضافه کن، و اندازه پیشنهادی را بگذار. Control Audio via OBS را روشن کن تا صدا از OBS بیاید.

چطور در OBS استفاده کنم؟

  1. پنل: https://donate.atomicshop.ir/panel/
  2. وارد ابزار شو → «کپی لینک» → در OBS یک Browser Source جدید با همان URL.
  3. اندازه‌ها: آلارم ۸۰۰×۴۵۰ — لیست ۴۴۰×۵۲۰ — هدف ۳۶۰×۱۴۰ — برچسب ۳۴۰×۲۲۰ — دوناتون ۲۴۰×۳۲۰.
  4. داک استریم برای اسکیپ و تست: View → Docks → Custom Browser Dock با لینک کنترل پنل استریم.
  5. گیف جدا برای هر مبلغ: ابزار «گیف مرحله‌ای». گیف پیش‌فرض: ابزار «هشدار رویداد جدید». فایل را در OBS نگذار؛ لینک آلارم Browser Source است.
